## Rules

- TypeScript strict mode
- Do not use any unless necessary
- Reuse existing components
- Do not duplicate API logic
- Do not change database schema without explaining migration
- Always run tests after modifying backend
- Always run TypeScript checks
- Never delete existing functionality without confirmation

## Workflow

1. Inspect existing code
2. Understand architecture
3. Create implementation plan
4. Implement
5. Run tests
6. Fix errors
7. Review changes
8. Summarize changes
